# BrewBuddy AI - Smart Coffee Cafe

A coffee cafe web app built with Python, Streamlit, and Groq AI.

## Features
- Digital menu with PKR prices
- AI Barista
- Coffee personality quiz
- Shopping cart and bill calculator
- Demo checkout and CSV ticket records

## Run
Install dependencies:
pip install -r requirements.txt

Start the app:
streamlit run app.py

## Security
Set GROQ_API_KEY using environment variables or Streamlit Secrets.
Never upload API keys to GitHub.
